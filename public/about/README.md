# About-page photos

This folder holds the photos used on the About page.

| File              | What it should be                                     | Recommended size |
| ----------------- | ----------------------------------------------------- | ---------------- |
| `storefront.jpg`  | Photo of the Red Barn Western Market in Sand Springs, OK | 1200 × 960 px (5:4) |

How to replace:

1. Take or pick a photo on your phone or computer.
2. Rename it exactly to one of the file names above (lowercase, `.jpg` extension).
3. Drop it into this folder (`/public/about/`) — overwriting the existing file.
4. Commit and push. The website rebuilds and the new photo appears.
