# About-page photos

These files are **placeholders**. Replace them with real photos any time —
no code changes needed, just drop in new files with the **same file names**:

| File              | What it should be                                     | Recommended size |
| ----------------- | ----------------------------------------------------- | ---------------- |
| `storefront.jpg`  | Photo of the Red Barn Western Market in Sand Springs, OK | 1200 × 960 px (5:4) |
| `team-1.jpg`      | Headshot of team member #1 (e.g. Owner)               | 400 × 400 px (square) |
| `team-2.jpg`      | Headshot of team member #2 (e.g. Manager)             | 400 × 400 px (square) |
| `team-3.jpg`      | Headshot of team member #3 (e.g. Yard Lead)           | 400 × 400 px (square) |
| `team-4.jpg`      | Headshot of team member #4 (e.g. Customer Care)       | 400 × 400 px (square) |

How to replace:

1. Take or pick a photo on your phone or computer.
2. Rename it exactly to one of the file names above (lowercase, `.jpg` extension).
3. Drop it into this folder (`/public/about/`) — overwriting the existing file.
4. Commit and push. The website rebuilds and the new photo appears.

If you'd like to update the names / roles / bios under each headshot,
edit `messages/en.json` and `messages/es.json` — search for the keys
`team1Name`, `team1Role`, `team1Body`, etc.
